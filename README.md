# MambaSleep-CVD

**Note: This repository is currently under active development and is not yet complete.**

MambaSleep-CVD is a pipeline for predicting cardiovascular disease (CVD) using physiological sleep signals. 

## Overview

This project explores the use of Coupled Mamba architectures for long-term cardiovascular disease (CVD) risk prediction using raw full-night polysomnography (PSG) data. The framework is designed to simultaneously fuse temporal and cross-modal dynamics from ECG, EEG, and EOG signals.


## Current content
At this stage, the repository includes a few standalone scripts that cover the data loading, model architectures, and model training and evaluation.

*Note: These scripts might require manual path adjustments to run locally before the final package is released.
